# 30-03 — APK "TechMenu Quản lý": vỏ Android mở `/quan-ly`, tự cập nhật, nút tải + mã QR

> Yêu cầu: **MGR-07, MGR-08**. Quyết định: QD-033 D2, D6; khuôn QD-030 D2 (APK tự cài + tự cập nhật). Giao diện: §B1, §B11.
> Plan là hợp đồng + nghiệm thu. Cần 30-02 xong.

**Mục tiêu:** điện thoại Android sạch quét mã QR ở trang quản trị → tải + cài APK → mở app → `/quan-ly` toàn màn hình → đăng
nhập; bản mới hiện "Cập nhật". App Thu ngân **không bị ảnh hưởng**.

## Hợp đồng

| Thành phần | Nội dung |
|---|---|
| Gradle — `android/app/build.gradle.kts` | Thêm `flavorDimensions("app")` với 2 flavor: `thuNgan` (giữ **nguyên** `applicationId = "vn.techmenu.thungan"`, tên, biểu tượng) và `quanLy` (`applicationId = "vn.techmenu.quanly"`, tên "TechMenu Quản lý", biểu tượng riêng). Cùng khóa ký |
| Mã nguồn | Code chung giữ ở `src/main` (cập nhật `CapNhat.kt`, màn mất mạng `TrangCuaApp.kt`). Phần riêng Thu ngân (kích hoạt, dịch vụ in, ☰ nổi) chuyển sang `src/thuNgan`. `src/quanLy`: một Activity WebView mở `{apiBase}/quan-ly`, giữ cookie, Back lùi trang, liên kết ngoài mở trình duyệt, tải tệp như 30-01 |
| Tự cập nhật | Dùng lại `CapNhat.kt`, tham số hóa theo app. Route sẵn có `app/api/android/latest` + `update/[file]` thêm tham số `?app=quan-ly` (mặc định = Thu ngân như cũ); `lib/android/phat-hanh.ts`: tệp chỉ mục riêng `android-quan-ly-latest.json`, mở rộng `TEP_HOP_LE_ANDROID` nhận `TechMenu-QuanLy-<phiên bản>.apk`. Tag GitHub `quan-ly-v<phiên bản>` |
| Phát hành | `android/scripts/phat-hanh.mjs` nhận `--app thu-ngan|quan-ly` (mặc định `thu-ngan` để lệnh cũ không đổi) |
| Trang tải | Thẻ "App quản lý trên điện thoại" ở `app/r/[slug]/admin/(protected)/page.tsx`: mã QR trỏ tới `/tai-app-quan-ly` (trang công khai mới: nút "Tải cho Android" + hướng dẫn iPhone 3 bước có ảnh) |

| Tên | Ở đâu | Kiểm |

| Kiểm máy ảo | `android/scripts/kiem-may-ao.mjs --app quan-ly` | Cài APK Quản lý → mở `/quan-ly` → đăng nhập chủ demo → Tổng quan; cài cạnh app Thu ngân, cả hai chạy |
| **Cài đè Thu ngân** | `android/scripts/thu-cap-nhat.mjs` | APK `thuNgan` build sau thay đổi cài đè lên bản Thu ngân đang chạy, **giữ kích hoạt + cài đặt máy in** |

## Lệnh + kỳ vọng

- `cd android && ./gradlew assembleThuNganRelease assembleQuanLyRelease` → 2 APK; `apksigner verify` cùng chứng chỉ.
- `node scripts/thu-cap-nhat.mjs` → tất cả "✓" (kể cả cài đè Thu ngân).
- `npm run test` → xanh.

## Cạm bẫy

- Thêm flavor đổi tên task Gradle ⇒ **sửa mọi script** đang gọi tên cũ: `phat-hanh.mjs` gọi `assembleRelease` (dòng 43),
  `thu-cap-nhat.mjs` gọi `assembleDebug` (dòng 39), kiểm thêm `kiem-may-ao.mjs`, `thu-in-lan.mjs`, CI — nếu không, bản Thu ngân
  kế tiếp không build được.
- `applicationId` Thu ngân **không được đổi** (QD-030 D6) — máy đang cài sẽ không lên bản mới.
- Mã gói `vn.techmenu.quanly` cố định sau lần phát hành đầu — chốt tên trước khi phát hành.
- APK Quản lý **không** cần quyền in nền / chạy khi khởi động máy — đừng chép `KhoiDongMay`/dịch vụ in sang flavor này (manifest riêng).
