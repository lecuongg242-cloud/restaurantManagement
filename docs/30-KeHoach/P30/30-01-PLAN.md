# 30-01 — ☰ → "Quản trị" trong app Thu ngân (Windows + Android), phiên đăng nhập riêng

> Yêu cầu: **DESK-13, ANDR-09**. Quyết định: QD-033 D1, D5 (sửa QD-026 D7). Giao diện: `00-TongQuan.md` §A1–A5.
> Plan là hợp đồng + nghiệm thu. **Chỉ bắt đầu sau khi chủ dự án chốt §A.**

**Mục tiêu:** máy quầy đang bán bằng tài khoản thu ngân → ☰ → **Quản trị** → đăng nhập chủ/quản lý → làm việc trong admin →
đóng → POS vẫn là thu ngân, không phải đăng nhập lại. Không sửa trang admin.

## Hợp đồng

| Thành phần | Nội dung |
|---|---|
| Windows — `desktop/main.mjs` | Mục menu **"Quản trị"** (dưới "Màn bếp", có vạch ngăn; tắt khi chưa kích hoạt). Mở `BrowserWindow` thứ hai, `webPreferences.partition = "persist:quan-tri"`, cùng `preload`/cờ an toàn như cửa sổ chính (không Node), tiêu đề "Quản trị — {tenantName}", tải `{apiBase}/r/{slug}/admin`. Đang mở → `focus()`. Gắn **cùng** bộ chặn điều hướng (`duocDieuHuong`, `moNgoai`, chặn webview, quyền) — tách thành hàm dùng chung cho mọi cửa sổ, không chép |
| Windows — tải tệp | `session.fromPartition("persist:quan-tri").on("will-download")` → hộp "Lưu tệp" của Windows (Xuất Excel, PDF mã QR) |
| Windows — đăng xuất máy | `dangXuatMayQuay` đóng cửa sổ Quản trị + `clearStorageData()` partition `persist:quan-tri` |
| Android — `QuanTriActivity.kt` (mới) | Activity riêng, WebView dùng **Profile "quan-tri"** (`androidx.webkit` `ProfileStore`, chỉ khi `WebViewFeature.isFeatureSupported(MULTI_PROFILE)`), mở `{apiBase}/r/{slug}/admin`. Thanh trên: "← Về Thu ngân" + "Quản trị — {tên quán}". Back: lùi trang, hết thì `finish()`. Cùng quy tắc liên kết ngoài / mất mạng như `MainActivity` (tách hàm dùng chung) |
| Android — WebView cũ không có MULTI_PROFILE | **Không** mở trong WebView chung (sẽ đá thu ngân). Mở trang admin bằng **trình duyệt của máy** + toast "Máy chưa hỗ trợ mở trong app — đã mở bằng trình duyệt" |
| Android — tải tệp | `setDownloadListener` → `DownloadManager` lưu vào Tải xuống (cookie của profile quản trị), thông báo "Đã tải {tên tệp}" |
| Android — menu ☰ nổi | Thêm mục **"Quản trị"** dưới "Màn bếp" (`MainActivity.kt` khoảng dòng 487). "Đăng xuất máy" xóa cookie + storage của profile "quan-tri" ngoài profile mặc định |
| Web | Không sửa. Quyền do `canAccess(role, "admin")` (owner/manager) quyết định như hiện tại |
| Phiên bản | Windows + Android tăng bản vá (1.0.x → bản kế); phát hành qua quy trình sẵn có (`desktop/scripts/phat-hanh.mjs`, `android/scripts/phat-hanh.mjs`) |

## Lệnh + kỳ vọng

- `npx playwright test -c playwright.desktop.config.ts` → toàn bộ xanh (cũ + 4 test mới).
- `cd android && ./gradlew assembleDebug && node scripts/kiem-may-ao.mjs` → tất cả bước "✓".
- `npm run test` → không đỏ thêm (web không đổi).

## Cạm bẫy

- **Một origin = một cookie** — lý do có cả đợt này. Đừng "tối ưu" bằng cách mở admin trong cửa sổ/WebView chính.
- Android: `CookieManager.getInstance()` là của **profile mặc định**; profile "quan-tri" phải lấy `profile.cookieManager`. Đăng xuất
  máy hiện chỉ xóa profile mặc định (`MainActivity.kt` ~dòng 531).
- Profile API phải gọi **trước** khi WebView tải trang đầu; đặt profile sau khi `loadUrl` là lỗi.
- Hiện **cả hai app chưa xử lý tải tệp** (không có `will-download` / `setDownloadListener`) — admin có Xuất Excel nên phải làm ở đây.
- Cửa sổ Quản trị Windows không được làm app "thoát xuống khay" như cửa sổ chính: ✕ là đóng hẳn cửa sổ đó.
