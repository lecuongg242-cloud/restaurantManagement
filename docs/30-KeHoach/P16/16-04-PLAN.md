# 16-04 — Xuất Excel mọi khối báo cáo

> Yêu cầu: **REPORT-19**. Phụ thuộc: không (khối mới của 16-02/16-03/16-05 dùng lại khi xong). Plan là hợp đồng + nghiệm thu.

**Mục tiêu:** mỗi khối báo cáo có nút "Xuất Excel"; có nút "Xuất toàn bộ" ra một file nhiều trang tính.

## Hợp đồng

| Thành phần | Nội dung |
|---|---|
| Định dạng | **Bước 1:** CSV UTF-8 có BOM (Excel mở đúng tiếng Việt), 0 thư viện mới. **Bước 2 (nếu chủ dự án muốn một file nhiều trang):** `.xlsx` — chọn thư viện ở bước này, ghi lý do vào SUMMARY |
| `lib/reports/export.ts` (mới, thuần) | `toCsv(columns: { key; label }[], rows: Record<string, unknown>[]): string` — số tiền là số nguyên (không dấu phân cách), ngày giờ theo giờ VN dạng `dd/MM/yyyy HH:mm` |
| Route `GET /r/{slug}/admin/reports/export?block=…&from=…&to=…` | Chỉ owner/manager; gọi **cùng** hàm lấy dữ liệu với khối trên màn (một nguồn số); ghi nhật ký xuất (ai, khối, khoảng ngày) |
| Tên file | `{slug}_{khoi}_{tu}_{den}.csv` không dấu |

## Test phải có

- `toCsv`: dấu phẩy, dấu ngoặc kép, xuống dòng trong tên món → escape đúng; BOM ở đầu; tiếng Việt giữ nguyên.
- Tổng cột tiền trong file = số trên màn cho cùng khoảng ngày (test route với dữ liệu mẫu).
- Cashier gọi route → 403; không có dữ liệu → file chỉ có dòng tiêu đề.
- Khối danh sách khách (16-05) chỉ xuất được khi owner (PII).

## Cạm bẫy đã biết

- Excel bản Việt dùng dấu `;` làm phân cách với một số cài đặt vùng ⇒ thử trên máy Windows tiếng Việt; nếu lỗi, thêm dòng
  `sep=,` hoặc chuyển sang `.xlsx`.
- Không kéo quá 1000 dòng qua PostgREST — xuất danh sách dài phân trang ở server.
